# frontend

ReviewStack 前端。在 #3 專案骨架完成前，這個目錄可以獨立安裝與啟動。

技術：Vite、React、TypeScript、Tailwind CSS。

## 啟動

```bash
cd frontend
npm install
npm run dev
```

瀏覽器打開終端機顯示的網址（預設 http://localhost:5173）。

## 指令

- `npm run dev`：開發伺服器
- `npm run lint`：oxlint
- `npm run build`：型別檢查並產出正式版
- `npm run preview`：預覽正式版產出
